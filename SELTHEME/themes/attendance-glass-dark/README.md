# attendance-glass-dark

`SELTHEME` 下的考勤业务示例主题包。

包含：

- `tokens.css`：考勤工作台使用的深色玻璃主题变量
- `components.css`：业务示例主题的聚合入口
- `components/layout.css`：考勤工作台示例骨架
- `components/buttons.css`：考勤按钮、状态芯片和切换按钮
- `components/forms.css`：考勤录入表单示例
- `components/tabs.css`：分段导航和语言/主题切换示例
- `components/tables.css`：考勤列表示例
- `components/trees.css`：层级关系示例
- `components/overlays.css`：考勤空态和提示示例
- `assets/`：主题背景雾化和光效 SVG 资产
- `preview/index.html`：主题静态预览入口

适用场景：

- 第一阶段主数据工作台
- 深色桌面业务台账
- 需要中日双语切换的后台录入页面

说明：

- 该主题保留为考勤业务示例包，不再作为跨项目通用后台主题继续扩展
- 跨项目后台项目应优先使用 `../admin-workbench-dark`
