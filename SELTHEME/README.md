# SELTHEME

独立液态玻璃主题目录。

包含：

- `themes/liquid-glass/`：正式毛玻璃主题包
- `themes/liquid-glass/tokens.css`：主题变量
- `themes/liquid-glass/components.css`：液态玻璃组件样式
- `themes/liquid-glass/assets/`：自生成 SVG 图片资产
- `themes/liquid-glass/preview/index.html`：独立主题预览页
- `doc/`：主题说明文档

当前目录不再把主题文件平铺在根目录下，后续若新增其他主题，也应继续放在 `themes/` 下按主题名分包收敛。
